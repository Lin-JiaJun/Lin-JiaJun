## Engineering principles

- Treat model output as evidence to evaluate, not truth to assume
- Make uncertainty, failure states, and human decisions explicit
- Design long-running workflows to be observable, recoverable, and idempotent
- Protect user data by default and keep secrets out of repositories
- Measure product usefulness, not just benchmark scores
